# DplusD Detailing Center

Премиальный одностраничный сайт московского детейлинг-центра DplusD Detailing Center.

## Что реализовано

- строгий адаптивный интерфейс в чёрном стиле;
- услуги, акции, контакты, FAQ и реальные фотографии студии;
- форма записи с именем, телефоном, автомобилем, услугой, датой и временем;
- серверная валидация и сохранение заявок в Cloudflare D1;
- защита формы от простых спам-ботов;
- готовая точка расширения для уведомлений через Telegram Bot API.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run lint
npm test
```

## Основные файлы

- `app/page.tsx` — структура и интерактивность страницы;
- `app/globals.css` — дизайн и адаптивная вёрстка;
- `app/api/bookings/route.ts` — приём и валидация записей;
- `db/schema.ts` — структура таблицы заявок;
- `drizzle/` — миграции базы данных.

Telegram-токен и другие секреты не должны храниться в репозитории. При подключении бота используйте переменные окружения платформы размещения.
